How to Configure Gmail SMTP on Render Hosting

  1. Visit your Google Account security settings at myaccount.google.com/apppasswords (with 2-Step Verification active).
  2. Generate a new App Password named "AQUENZA Website" (Google will give you a 16-character code).
  3. Go to your Render Web Service dashboard → Environment tab.
  4. Add the secret variable: SMTP_APP_PASSWORD=your_16_char_code and click Save.
  5. The server will automatically reload and begin delivering real website enquiries immediately to aquenza.service@gmail.com!
